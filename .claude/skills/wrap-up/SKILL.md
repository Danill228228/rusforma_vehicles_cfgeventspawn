---
name: wrap-up
description: Завершить рабочую сессию компании — проверить данные, сформировать ежедневный отчёт, убедиться, что агенты записали выводы в память, закоммитить и отправить всё в git (контейнер одноразовый). Используй в конце каждой сессии или перед долгой паузой.
---
1. `./dzm validate` — исправь ошибки.
2. `./dzm kb index`, `./dzm board`, `./dzm report daily --save`.
3. `git status`: нет ли ценных файлов вне репозитория. Сторонние справочники в `/home/user/<owner>/` не коммитим. Бинарники больше 10 МБ без Git LFS не коммитим.
   Коммерческая защита: если в коммит попадает что-то из `Development/Source|Models|Textures|Configs`, проверь видимость репозитория (`list_repos`). Если он public — не пушить и сообщить заказчику (решение D-012).
4. `git add -A && git commit -m "Компания: <итог сессии>"`, затем `git push -u origin <текущая ветка>`.
5. Заказчику — 3–5 строк: что сделано, что заблокировано, что дальше.
