---
name: research
description: Получить проверенный ответ о движке DayZ, моддинге или инструментах — сначала база знаний, затем исследование research-lead с сохранением результата в базу. Используй для любых технических вопросов вида «как устроено», «можно ли», «где взять».
argument-hint: "[вопрос]"
---
1. `./dzm kb search "<ключевые слова из вопроса: $ARGUMENTS>"`. Если есть запись VERIFIED или PARTIAL по вопросу — ответь по ней со ссылкой и не запускай исследование.
2. Иначе: `./dzm task add --type research --assignee research-lead --title "..." --budget 40000` и делегируй research-lead с точными вопросами и ID задачи.
3. Итог: запись в Knowledge_Base (статус и источники), `./dzm kb index`, `./dzm run log`.
4. Ответ заказчику — коротко: вывод, уровень уверенности, источники, что ещё нужно проверить экспериментом.
