# HR — отдел персонала

**Сотрудник:** `hr-director` (sonnet) · промпт: `.claude/agents/hr-director.md` · память: `.claude/agent-memory/hr-director/`

## Что здесь лежит
- `roster.json` — единый реестр сотрудников (данные `./dzm`); `ROSTER.md` — витрина, генерируется.
- `STAFFING_PLAN.md` — оргструктура, обоснование состава, триггеры найма.
- `templates/AGENT_TEMPLATE.md` — шаблон нового агента для `./dzm hr hire`.
- `retired/` — файлы выведенных из штата агентов (история сохраняется).

## Как работает найм (реально)
1. CEO вызывает `/hire` или делегирует hr-director.
2. `./dzm hr hire ...` создаёт `.claude/agents/<имя>.md`, запись в ростере и память агента.
3. HR дописывает инструкции. `./dzm roster --check` и `claude plugin validate .claude/agents` должны пройти.
4. Агент доступен для делегирования сразу, без перезапуска сессии.
