# База знаний AI Company DayZMods

Единая память компании о DayZ. Её читают и пополняют все технические агенты.

- **Искать:** `./dzm kb search "слова запроса"` (должны встретиться все слова). Перед любым исследованием — обязательно.
- **Добавить:** `./dzm kb new --path <Раздел>/<тема>.md --title "..." --status VERIFIED|PARTIAL|HYPOTHESIS --sources "..."`, заполнить разделы, затем `./dzm kb index`.
- **Индекс:** `INDEX.md` (генерируется). **Источники и доступ к ним:** `SOURCES.md`.
- **Правила и формат записи:** `../Company/Rules/RESEARCH_PROTOCOL.md`. `./dzm validate` проверяет поля и минимальное число источников.

| Раздел | Что хранится |
|---|---|
| DayZ_Engine | архитектура, объекты и события, действия, инвентарь, повреждения, оружие, звук, UI, ИИ, физика, реестр ограничений |
| Enforce_Script | язык: типы, классы, наследование, modded, память, идиомы |
| Configs | config.cpp и классы Cfg*, XML Central Economy |
| Modding | структура модов, слои скриптов, сборка, совместимость |
| Networking | клиент-сервер, RPC, NetSync, JIP |
| Animations | CfgMoves, команды персонажа, граф анимаций |
| Vehicles | транспорт, спавн техники в CE |
| Research | планы исследований, оценки реализуемости |
| Tools | DayZ Tools, Blender, окружение компании, платформа агентов |
