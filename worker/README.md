# Сервер магазина DAWNLINE

Небольшой сервер на Cloudflare Workers (бесплатный тариф). Все данные хранятся в самом воркере: это Durable Object со встроенной базой SQLite.

Что он делает:
- **вход через Steam**: проверяет ответ Steam, чтобы вход нельзя было подделать;
- **продукты мастерской**: название, описание, цена, фото, ссылка на скачивание. Всё это добавляется в админке на сайте;
- **верификацию покупателей**: название проекта, Discord ID, IP, Port, QPort и рассказ о проекте. Заявку одобряет администратор;
- **покупку через Boosty**: заказ, донат с Steam ID, подтверждение администратором и мгновенная выдача доступа;
- **выдачу продукта**: ссылку на скачивание и инструкцию видят только покупатели;
- **отзывы** (только от покупателей) и **лайки**;
- **админку**: верификация, пополнения, продукты, игроки, возвраты, блокировка.

## Переменные воркера

| Имя | Тип | Значение |
|---|---|---|
| `SITE_URL` | Text | `https://danill228228.github.io/rusforma_vehicles_cfgeventspawn/` |
| `SESSION_SECRET` | Secret | длинная случайная строка (не короче 24 символов) |
| `ADMIN_CLAIM_CODE` | Secret | одноразовый код администратора: вводится в кабинете → «Я владелец магазина» |
| `BOOSTY_URL` | Text | `https://boosty.to/tufelka` (можно поменять в админке) |
| `STEAM_API_KEY` | Secret | необязательно: ник и аватар игрока подтягиваются надёжнее |
| `ADMIN_STEAM_IDS` | Text | необязательно: Steam ID администраторов через запятую |
| `CURRENCY` / `CURRENCY_SIGN` | Text | `rub` / `₽` |

Привязка хранилища: Durable Object `SHOP` → класс `Shop` (SQLite).

## Покупка через Boosty

1. Игрок на странице продукта нажимает **«Купить через Boosty»**. Сайт создаёт заказ с кодом `DL-…` и сообщением для доната вида `SteamID 7656… · DL-…`.
2. Кнопка **«Перейти на Boosty»** копирует сообщение и открывает https://boosty.to/tufelka. Игрок донатит сумму, равную цене продукта, и вставляет сообщение.
3. Тебе приходит уведомление Boosty о донате. В админке → «Заказы через Boosty» найди заказ с тем же Steam ID и суммой и нажми **«Донат пришёл»**. Доступ к продукту и ссылка на скачивание появятся у игрока сразу.

Если донат пришёл без заказа, игрока можно найти в админке → «Игрок» и нажать «Выдать продукт». Там же можно забрать доступ.

У Boosty нет официального API для уведомлений о донатах, поэтому донат подтверждает администратор.

Ссылку на Boosty можно поменять в админке → «Boosty».
