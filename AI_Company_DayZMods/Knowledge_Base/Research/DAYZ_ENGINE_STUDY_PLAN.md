# План глубокого изучения DayZ Engine

Проект **PRJ-0002** · задачи T-0016 … T-0039 на доске (`./dzm task list --project PRJ-0002`) · исполнители: research-lead, lead-engineer, config-build-engineer, modeler-3d, qa-lead, media-director.

## Принципы
- Каждая тема даёт запись в базе знаний с источниками и статусом. Ответы на ключевые вопросы — обязательная часть записи.
- Порядок задают зависимости, и `./dzm` их проверяет: транспорт нельзя изучать раньше сетевой модели и системы действий.
- Источники по убыванию надёжности: DayZ-Samples, DayZ-Central-Economy и вики BI → ванильные скрипты → моды сообщества.
- Если для проверки нужен запуск игры, эксперимент оформляется как сценарий для ПК заказчика.
- Имена API в ключевых вопросах — ориентиры из опыта команды. Их существование и сигнатуры проверяются в самой задаче.
