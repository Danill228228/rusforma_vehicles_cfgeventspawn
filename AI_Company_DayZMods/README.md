# AI Company DayZMods

Виртуальная студия моддинга DayZ из ИИ-агентов Claude Code. Каждый сотрудник — отдельный агент со своей должностью, инструкциями, инструментами, моделью и постоянной памятью. Работа идёт через общую доску задач, базу знаний и обязательный контроль качества.

## Как пользоваться
Откройте сессию Claude Code в этом репозитории и пишите как руководителю студии:
- «Новый заказ: стрельба из открывающегося люка УАЗа» → `/new-project`: проект, оценка реализуемости, план и бюджет на утверждение.
- «Что мы знаем про RPC?» → `/research`: ответ из базы знаний или исследование с сохранением.
- «Проверь T-0021» → `/qa-gate`. «Нужен специалист по UV» → `/hire`. «Отчёт» → `/ceo-report`. «Заканчиваем» → `/wrap-up`.

## Оргструктура
CEO (основная сессия) → project-planner, hr-director, qa-lead, research-lead, lead-engineer (→ config-build-engineer), modeler-3d, media-director (→ screenwriter, video-editor). Подробно: `Company/HR/STAFFING_PLAN.md`, ростер: `./dzm roster`.

## Где что лежит
| Путь | Содержимое |
|---|---|
| `../CLAUDE.md` | общие правила для всех агентов и протокол CEO (загружается автоматически) |
| `../.claude/agents/` | 10 сотрудников-агентов |
| `../.claude/skills/` | рабочие процедуры CEO: `/new-project`, `/research`, `/qa-gate`, `/hire`, `/ceo-report`, `/wrap-up` |
| `../.claude/agent-memory/` | личная память каждого агента |
| `Company/` | устав и регламенты (`Rules/`), CEO, HR, отделы с дорожными картами, доска задач, инструменты |
| `Knowledge_Base/` | база знаний DayZ, реестр источников, план изучения движка |
| `Projects/` | проекты: активные, завершённые, архив |
| `Development/` | исходники, модели, текстуры, скрипты, конфиги, сборки |
| `QA/` | автотесты, реестр ошибок, отчёты проверок |
| `Media/` | сценарии, раскадровки, футаж, готовые ролики |
| `Reports/` | ежедневные, недельные (отчёт CEO), проектные отчёты |
