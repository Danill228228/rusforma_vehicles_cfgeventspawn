# Отдел планирования

**Сотрудник:** `project-planner` (sonnet) · промпт: `.claude/agents/project-planner.md`

## Миссия
Правильная последовательность работ и экономия ресурсов: этапы, задачи, зависимости, приоритеты, бюджеты токенов и отчёты.

## Входы и выходы
- Вход: PROJECT.md нового проекта, доска (`./dzm task list --all`), база знаний, учёт запусков (`./dzm run list`).
- Выход: задачи в `./dzm` со связями и бюджетами, критический путь, отчёты в `Reports/`.

## Стандарты
- Этапы проекта мода Э0–Э5 (в промпте агента); бюджеты S/M/L и модели (`Company/Rules/RESOURCES.md`).
- Принцип работы: получить задачу → проанализировать → разбить на этапы → определить специалистов → выдать задачи → получить и проверить результаты → передать следующему отделу.

## Дорожная карта обучения
| Этап | Что освоить | Результат |
|---|---|---|
| 1 | CLI `./dzm`, гейты статусов, шаблон этапов | первый проект разложен без ручных исправлений CEO |
| 2 | калибровка бюджетов по фактам | таблица «тип задачи → реальные токены» в памяти планировщика после 10 задач |
| 3 | критический путь и параллельность | правило «что можно параллелить» для типовых проектов; еженедельный отчёт CEO |
