# Отдел 3D-моделирования

**Сотрудник:** `modeler-3d` (sonnet) · помощники по триггерам из `Company/HR/STAFFING_PLAN.md`.

## Миссия
Игровые 3D-объекты для DayZ: оружие, техника, здания, предметы, мебель, окружение — с LOD, служебными геометриями, UV, текстурами и материалами, готовые к интеграции.

## Конвейер (что реально работает, проверено 2026-11-20)
| Шаг | Инструмент | Статус |
|---|---|---|
| Моделирование, UV, LOD, сохранение .blend | Blender 5.3 headless (`Company/Tools/setup_blender.sh`) | работает: smoke-тест 3 LOD (588/108/12 треугольников), UV, экспорт FBX/OBJ/GLB |
| Текстуры (рисование, маски, атласы) | ImageMagick, Pillow, запекание в Blender | работает |
| Экспорт P3D (MLOD) | аддон Arma 3 Object Builder для Blender (GPLv3) | гипотеза для DayZ: проверка — задача T-0033 |
| PAA-текстуры, бинаризация, Object Builder | DayZ Tools на ПК заказчика | только у заказчика |
| Substance Painter | коммерческая программа с графическим интерфейсом | недоступна; заменяем запеканием в Blender |

## Выход на каждую модель
`Development/Models/<проект>/<объект>/`: `.blend`, скрипт генерации `build_*.py`, экспорт, `README.md` (полигоны по LOD, геометрии, memory-точки, материалы). Текстуры — `Development/Textures/<проект>/`.
