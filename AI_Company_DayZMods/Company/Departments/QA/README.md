# Отдел контроля качества (QA)

**Сотрудник:** `qa-lead` (sonnet; для тяжёлого разбора первопричин — запуск на opus по решению CEO) · промпт: `.claude/agents/qa-lead.md`

## Миссия
Ни один результат не уходит заказчику без доказательств. QA проверяет, регистрирует ошибки по стандарту, делает повторные тесты и выносит вердикт.

## Рабочие места
- `QA/Tests/` — автотесты (сейчас: `test_company.py` — 13 тестов инфраструктуры `./dzm`).
- `QA/Bugs/` — реестр ошибок (`bugs.json` и витрина `BUGS.md`).
- `QA/Reports/` — отчёты о проверках `QA-<задача>-<дата>.md`.
- Регламенты: `Company/Rules/QUALITY_GATES.md` (10 стадий, стандарт ошибки, DoD).

## Что QA может сейчас и что нет
| Может в контейнере | Только с ПК заказчика |
|---|---|
| автотесты, парсинг XML, проверка config.cpp, статический разбор Enforce Script, сравнение с эталонами BI, ffprobe | компиляция скриптов игрой, запуск сервера и клиента, логи script.log и RPT, FPS, сеть с несколькими клиентами |
