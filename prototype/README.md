# Прототип P0: можно ли стоять в люке Offroad_02 и стрелять на ходу

Одноразовый тестовый мод **HatchP0**. Он отвечает на один вопрос: даст ли движок DayZ 1.30 закрепить игрока на крыше ванильного M1025 так, чтобы на ходу работало штатное оружие. От ответа зависит вся дальнейшая разработка (см. `docs/hmmwv_hatch/RESEARCH_REPORT.md`, раздел 7.3).

> ⚠️ Только для **DayZDiag_x64.exe**. На обычном клиенте и сервере мод ничего не делает (код под `#ifdef DIAG_DEVELOPER`). Не ставьте его на боевой сервер.

## Что проверяем

| Тест | Вопрос |
|---|---|
| **T1** | Держит ли `LinkToLocalSpaceOf()` игрока на крыше: стоя, на 20, 40 и 60 км/ч |
| **T2** | Работает ли оружие у привязанного игрока: подъём, прицел, выстрелы |
| **T3** | Держит ли движок игрока на крыше **без** явной привязки (в конфиге мода у Offroad_02 добавлен `animPhysDetachSpeed = 30`) |
| **T4** | Режим «в люке»: игрок опущен в крышу на 0.7 м, коллизия и гравитация выключены. Как это выглядит и держится ли |
| **T5** | Блокировка ходьбы: игрок не уходит с точки, но может поворачиваться и целиться |

## Установка

1. Скопируйте папку `prototype/@HatchP0` в папку игры DayZ (рядом с `DayZDiag_x64.exe`).
2. Запустите офлайн-миссию:
   ```
   DayZDiag_x64.exe -mod=@HatchP0 "-mission=.\Missions\dayzOffline.chernarusplus" -nosplash -noPause
   ```
   Если папки `Missions\dayzOffline.chernarusplus` нет, возьмите её из официального репозитория [DayZ-Central-Economy](https://github.com/BohemiaInteractive/DayZ-Central-Economy).
3. Признак, что мод загрузился: при нажатии `Ctrl+Num9` в чате появится строка `[HatchP0] ...`.

Готовый `HatchP0.pbo` собран без подписи скриптом `tools/pack_pbo.py`. Если игра его не примет, пересоберите:
```
python tools/pack_pbo.py prototype/HatchP0 prototype/@HatchP0/addons/HatchP0.pbo --prefix HatchP0
```
или соберите штатно через DayZ Tools → Addon Builder (исходная папка `prototype/HatchP0`, prefix `HatchP0`).

## Подготовка в игре

1. Встаньте на **длинную прямую дорогу**: автопилот едет строго прямо 15 секунд, на 60 км/ч это около 250 м.
2. Script Console → вкладка Enforce Script → вставить и запустить `tools/hmmwv_hatch/diag_offroad02_console.c`. Он поставит Offroad_02 в 6 м перед вами и заодно запишет в лог диагностику люка.
3. Выдайте себе автомат (там же, в Script Console):
   ```c
   PlayerBase p = PlayerBase.Cast(GetGame().GetPlayer());
   EntityAI w = p.GetHumanInventory().CreateInHands("AKM");
   if (w) w.OnDebugSpawn();
   ```
4. Поверните машину носом вдоль дороги. Автопилот толкает её туда, куда она смотрит.

## Управление

Все команды: **левый Ctrl + клавиша цифрового блока** (NumLock включён).

| Клавиши | Действие |
|---|---|
| `Ctrl+Num1` | **LINK**: поставить на крышу и привязать (`LinkToLocalSpaceOf`) |
| `Ctrl+Num2` | **PLACE**: поставить на крышу **без** привязки (T3) |
| `Ctrl+Num3` | **UNLINK**: отвязать, сбросить все режимы |
| `Ctrl+Num4` / `Num5` / `Num6` | автопилот 20 / 40 / 60 км/ч (автостоп через 15 с) |
| `Ctrl+Num0` | автопилот: плавная остановка |
| `Ctrl+Num7` | вкл/выкл режим «в люке» (T4) |
| `Ctrl+Num8` | вкл/выкл блокировку ходьбы (T5) |
| `Ctrl+Num9` | **DUMP**: подробный срез состояния в лог |
| `Ctrl+Num+` / `Ctrl+Num-` | точка крепления выше / ниже на 0.1 м |

## Порядок теста

Перед каждым шагом и после него нажимайте `Ctrl+Num9`: это ставит метку в логе.

1. **T1 стоя.** `Ctrl+Num1`. Вы на крыше? Попробуйте пройти (W): уходите ли с точки? Включите `Ctrl+Num8` и проверьте ещё раз.
2. **T2 стоя.** Поднимите оружие (ПКМ), прицельтесь, дайте очередь.
3. **T1 + T2 на ходу.** `Ctrl+Num4` (20 км/ч): держитесь ли вы на крыше, стреляется ли? Затем `Ctrl+Num0`. Повторите на `Ctrl+Num5` (40) и `Ctrl+Num6` (60).
4. **T3.** `Ctrl+Num3`, затем `Ctrl+Num2` (без привязки), затем `Ctrl+Num4`. Едет ли игрок вместе с машиной или соскальзывает?
5. **T4.** `Ctrl+Num3`, `Ctrl+Num1`, `Ctrl+Num7`. Посмотрите от третьего лица, как торчит персонаж. Подберите высоту `Ctrl+Num+`/`Num-`. Повторите автопилот 20/40 и стрельбу.
6. В конце `Ctrl+Num3`.

### По желанию: проверка по сети

Это нужно, чтобы понять, как привязанного игрока видят **другие**. Запустите локальный диаг-сервер с этим модом (в `serverDZ.cfg` для теста `verifySignatures = 0`) и подключитесь клиентом DayZDiag с тем же `-mod=@HatchP0`. Второй человек со вторым клиентом смотрит со стороны и нажимает `Ctrl+Num9`. Его лог покажет, где он видит стрелка (строки `DUMP_OTHER`).

## Что прислать

1. **Лог.** Файл `script_*.log` из `%LOCALAPPDATA%\DayZ\` (при тесте по сети ещё и лог сервера из папки `-profiles`). Достаточно строк с `[HATCHP0]` и `[HATCHDIAG]`.
2. **Короткий итог по каждому шагу:** держит, падает, дёргается или проваливается; стреляется или нет.
3. По возможности **скриншот** режима «в люке» от третьего лица.

## Как читать строки лога

```
[HATCHP0][OFFLINE] TICK cmd=MOVE linkedEnt=Offroad_02 floorEnt=Offroad_02 slidingOff=0 parent=none inVehicle=0 raised=1 speed=39.8kmh posMS=<…> drift=0.03m
```
* `linkedEnt`: к чему физически привязан игрок. `Offroad_02` означает, что привязка держит.
* `slidingOff=1`: движок «срывает» игрока с движущегося объекта.
* `parent` / `inVehicle`: если привязка делает игрока «пассажиром», оружие может блокироваться.
* `drift`: на сколько метров игрок сместился от точки крепления (норма до ~0.1 м).
* События `EVENT_LINK_LOST` и `EVENT_DRIFT` означают потерю привязки и уход с точки больше чем на 1 м.
* `FIRE ...`: каждый выстрел с состоянием в этот момент.

## Что решает результат

| Результат | Что дальше |
|---|---|
| T1 и T2 работают до 60 км/ч | Делаем механику по плану: стрелок привязан к машине, обычное оружие |
| Работает только стоя или на малой скорости | Ограничиваем выход в люк скоростью или ищем другой способ привязки |
| T1 не работает, T3 работает | Используем удержание движком (`animPhysDetachSpeed`) вместо явной привязки |
| Ничего не держит | Стрельба из люка на ходу в 1.30 невозможна без обходных путей; обсуждаем варианты |
